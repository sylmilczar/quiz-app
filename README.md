# CosmicQuiz 🌌

CosmicQuiz to interaktywna aplikacja quizowa zawierająca różnorodne pytania z wielu dziedzin, zbudowana przy użyciu React i TypeScript. Sprawdź swoją wiedzę z zakresu:

- 🦁 Świata zwierząt
- 🚀 Kosmosu i astronomii
- 🧪 Chemii
- 🔬 Nauki
- 🗺️ Geografii
- 📚 Historii
- 🎭 Kultury popularnej

## ✨ Funkcje

- 🎯 Różne poziomy trudności (łatwy, średni, trudny)
- 📊 Wybór liczby pytań (5, 10 lub 20)
- 🎨 Nowoczesny interfejs użytkownika z wykorzystaniem Tailwind CSS
- 📱 Responsywny design
- ✅ Natychmiastowa informacja zwrotna po każdej odpowiedzi
- 📈 Podsumowanie wyników po zakończeniu quizu

## 🚀 Technologie

- React 19
- TypeScript
- Tailwind CSS
- Vite
- React Router DOM
- clsx (dla warunkowego stylowania)

## 💻 Instalacja

1. Sklonuj repozytorium:

```bash
git clone https://github.com/sylmilczar/quiz-app.git
cd quiz-app
```

2. Zainstaluj zależności:

```bash
npm install
```

3. Uruchom aplikację w trybie deweloperskim:

```bash
npm run dev
```

Aplikacja będzie dostępna pod adresem `http://localhost:5173`

## 🛠️ Dostępne Skrypty

- `npm run dev` - uruchamia aplikację w trybie deweloperskim
- `npm run build` - buduje aplikację do wdrożenia
- `npm run typecheck` - sprawdza typy TypeScript
- `npm run lint` - sprawdza kod pod kątem błędów i stylu
- `npm run preview` - podgląd zbudowanej aplikacji

## 🎮 Jak Grać

1. Wybierz poziom trudności i liczbę pytań na ekranie startowym
2. Kliknij "Rozpocznij grę"
3. Odpowiadaj na pytania, wybierając jedną z dostępnych odpowiedzi
4. Po każdej odpowiedzi zobaczysz, czy była poprawna
5. Na końcu quizu otrzymasz podsumowanie swoich wyników
